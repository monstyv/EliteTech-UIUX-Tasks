# Task 3 — Mobile App Redesign

## App selected
YouTube (conceptual redesign).

## Specific pain point
The normal video-feed experience can make it difficult for a user who already knows what they want to watch to stay focused. This redesign introduces a simple **Focus Mode** concept.

## Improvements
1. **Focus Mode** — reduces the emphasis on distracting recommendations.
2. **Continue Watching** — places unfinished videos directly below the focus controls.
3. **Progress bars** — make unfinished content easy to scan.
4. **Clear hierarchy** — separates navigation, focus controls and content.
5. **One-tap interaction** — Focus Mode can be enabled directly from the banner.

## Prototype
Open `index.html` in a browser. The “Turn on” button changes the interface into Focus Mode.

## Deliverable
A redesigned mobile prototype plus explanation of the design decisions.
